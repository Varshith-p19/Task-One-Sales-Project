Sales Data Cleaning Project – README

Project Overview

This project focuses on cleaning and preprocessing a Sales dataset using Python (Pandas) and optionally Excel.
The dataset contained several real-world data quality issues such as:

Missing values

Duplicate rows

Inconsistent text formatting

Mixed date formats

Incorrect data types

Non-uniform column names

This project demonstrates a complete end-to-end data cleaning pipeline, which is one of the most important steps in data analysis.
